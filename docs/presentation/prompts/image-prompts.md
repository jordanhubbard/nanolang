# NanoLang image prompts

The presentation uses the existing NanoLang mascot as its character source.
New assets must keep the character recognizable, use developer-facing settings,
remain text-free, and leave negative space for slide copy. Record each prompt
and output in `qa-ledger.md`.

## `nanolang-mascot.png`

Adapt `userguide/Nanolang_Mascot.png` into a clean presentation illustration of
the NanoLang character reviewing readable source and NanoISA bytecode in a dark
graphite developer workspace. Preserve the character design and use warm orange
diagnostic paths, NanoLang green evidence accents, and cool blue VM depth. No
readable text, logos, watermarks, or Literate-AI application-foundry imagery.
