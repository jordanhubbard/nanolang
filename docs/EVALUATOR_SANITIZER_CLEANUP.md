# My evaluator cleanup contract

My full495e evaluator suite passes ordinarily on Linux and Darwin. The sanitizer suite stops at the terminal-match control and reports20,887 leaked bytes in614 allocations. Its stacks include earlier completed effect and async cases; I do not attribute all of them to the terminal child.

My first correction has two bounded owners. My effect registry owns its vector, definition names, module names, operation vector, operation names and return names, parameter vectors and copied parameter names. Parameter type metadata remains borrowed from the AST and must not be freed by the registry. My async-function and await AST wrappers own their respective child nodes and recursively destroy them. I preserve declaration admission, borrowed type metadata and all evaluator behavior.

Handler bindings, callable results, record temporaries and terminal fixture cleanup require separate lifetime review before execution. I retain existing full-suite assertions and leak detection. These first changes alone are not permission to replay known remaining failures or evidence of full qualification.

My handler binding correction preserves my existing value-copy rules for records and strings. A callable argument receives an independent name/signature before binding. Before retiring the parameter range, I preserve record, tuple and string results in the Environment result arena; a returned callable that aliases a parameter receives its own name/signature. I retain lexical return flags and target identity. I then release the binding names and owned values through my existing scope destructor. I do not change the lifetime of the caller argument or interpret borrowed AST type facts as owned.

Independent review rejects immediate callable destruction in my handler correction: record and tuple graphs deliberately borrow callable leaves, so a top-level result copy does not establish their ownership. I extend my existing Environment result arena with top-level callable retirement instead. Each retired entry uniquely owns its name/signature; record and tuple leaf traversal remains borrowed. Every removed callable binding moves to this arena, including ordinary block, call, loop and handler scopes. My top-level callable return copies remain independent. The arena outlives all evaluator scopes and frees these descriptors at Environment teardown. Failed retirement preserves the input owner and remains fatal under my existing scope policy. I require direct and nested callable escape controls before qualification.
