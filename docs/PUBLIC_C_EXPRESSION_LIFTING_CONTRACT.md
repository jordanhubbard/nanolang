## My lowering invariants

I add a typed value plan with an explicit destination and completion state. A value-producing path assigns its private result slot exactly once before continuation. A path ending in enclosing return, break or continue has no value continuation. I validate every reachable fallthrough path; a path lacking a value is refused instead of initialized with fabricated zero/void. Result kind and nominal owner agree at every continuing join. FLOAT values retain their bits and use existing arithmetic/format helpers; STRING values retain the established borrowed/stable-snapshot lifetime contract; a C union copy retains its full tag/payload by value.

I emit ordinary C99/C11 declarations and scoped statements before a consuming operation. A block opens a real lexical scope, emits preceding statements, and assigns its last value to an outer result slot only on a continuing path. Match lowering snapshots the scrutinee once, opens each payload scope before its guard, continues to later arms on false guards, and assigns the selected arm result before reaching a private continuation label. A nested match has independent slots/labels and restores outer bindings. Illegal runtime tags retain checked termination, never default to the last variant.

For compound values I snapshot earlier operands before lifting later operands. I preserve callee-before-arguments and left-to-right arguments for the admitted direct-call path, including cases where an earlier value would otherwise be reread after a later side effect. I retain separate sequential scalar constructor-field evaluation when those fields require lifting. For conditional/short-circuit values I place each branch's prerequisites inside that branch; an unselected return, mutation, assertion or call does not execute. I do not use C argument evaluation order as a source-order guarantee.

I preserve `return` as a real enclosing function return and break/continue as exits to their enclosing source loop. I introduce no artificial helper function or wrapper loop around a value. Control-only branches can bypass slot assignment only when they also bypass every consumer of that slot. I must inspect statement termination and lexical binding cleanup together; a syntactically final return does not authorize reading an unassigned result along another branch. Nested source loops retain their own targets.

All temporary names, result slots and labels use the existing private namespace. Planning and final emission reset counters, result context, lexical scopes and first-error state as specified by the existing staged publication contract. I do not mutate retained source AST ownership or keep metadata after the compiler invocation. A compiler planning pass may repeat analysis/emission into a private staging stream; it never executes source effects.
