# Union native target and subsequent public boundary

Status: reviewable design only after private executor bf6d2dae2. No production edit or build. This refines the native/public portions of NANOISA_UNION_FIELD_CONSUMER_DESIGN.md using the qualified ordinary HALT baseline and private execution receipt. In particular the older proposal that initializer HALT prevents entry is superseded: initializer activation halts and drains, then entry runs once. Some-only proof, conservative None-to-payload rejection, and historical read-before-replacement precision limits are unchanged.

## Actual entry map and phase order

`nvm2c.c:nvm2c_emit` currently selects map source handling via `nvm_record_map_route`, otherwise `nvm2c_emit_core`. The core separately routes arrays/mixed profiles; unhandled ownership goes to `nvm_verify_owned_module`/owned emission or refuses. Canonical record storage is chosen only for record-array/map scopes. No union entry exists. `nvm2c_map_private.inc` demonstrates the ownership pattern: fresh source plan, independent image copy, free source plan, static image target/emission, image destruction after generated text is independent.

The next private route can precede public VM enrollment. It must take only a source module, own its fresh union constructor and independently reconstructed image, and never accept caller-supplied proof, context or image. It does not use VmUnionFieldPrivate or run a VM. Proposed macro-only declaration in a new private native header:

```
char *nvm2c_emit_union_field_private(const NvmModule *, char *error, size_t error_size);
```

Return ownership matches nvm2c_emit: caller frees successful generated text; failure returns NULL, destroys all temporary owners and sets bounded diagnostic text when provided. No partial generated text is published. This is a native consumer API, not publication eligibility. Public nvm2c_emit and all existing core callers remain literal NULL-union routes with byte-identical old outputs.

Inside nvm2c's owning TU, propose static `nvm2c_union_image_emit(image,error,size)` and `nvm2c_union_target(image,...)`. The latter is an independently validating target over immutable copied getters; no public trusted-image entry. The existing image-lifetime module borrow in union_field_vm_image_private.h must be explicitly extended/renamed as a consumer-internal borrow rather than implying that a public image getter grants authority. It remains exclusively stable and image-owned. Keep the current core signature as a wrapper; a separate core implementation receives a distinct union image/context pointer alongside the existing map parameters, rejecting simultaneous selections. Thread the local union context through simulation and function emission; do not add fields to old plans, owners, VmState, VmHeap or Analysis.

Public VM can remain closed throughout native qualification. Its later route is a distinct borrowed-state supervisor: vm_execute currently selects record maps then arrays; vm_execute_record_arrays validates idle state and drains initializer results, while generic vm_execute leaves ordinary HALT residue. A public union route cannot call the private owner and copy an INT back: it must preserve caller global identity, ordinary heap/collector metadata, stack result semantics and repeated invocations. It needs same-invocation owned proof/context, fresh capacity-based import validation against historical union/record obligations, checked stack reserve and direct-call/resume refusal closure. Public verifier, conversion/save/load, VM dispatch and native public selection must be activated atomically only after that route qualifies. No publisher is included.

## Independent target and exact shape context

Validate complete image counts, functions/parameter rows, header/root signatures, initializer identity, every nominal descriptor, both layouts/variants/fields, frozen origins and every base/site row. All256 opcode byte values need an explicit constructor-to-target audit; syntax eligibility alone is insufficient. Preserve INVALID for malformed copied correspondence, UNRESOLVED for explicit unsupported target domains, LIMIT for the target allowance and MEMORY for allocations. An early unsupported row cannot hide later observed malformed correspondence.

Nominal identity is not layout identity: record ordinal0 resolves layout1 and union ordinal0 resolves layout0. Both variants resolve their declared ordinal and field slice; the payload alternative may be ordinal0 or1. There is one exact INT-payload and one empty alternative. Never reuse the map target's ordinal==layout gate or infer nominal identity from names. A site-dependent native helper reads the copied site operation, not a record ordinal through a union accessor. PACK must match exact allocation receiver/result facts; payload GET must match the payload variant subset and INT result; record GET/SET must preserve UNION representation and all historical replacement possibilities. Union payload SET stays refused. STRUCT_NEW's zero-field behavior is incompatible with this record; STRUCT_GET-on-UNION remains the constructor refusal. Record STRUCT transport, if present in an actual required original, needs deliberate exact translation or a reported target restriction, not accidental generic fallback.

A dormant NOT_ESTABLISHED site is not dynamic safety evidence. Native emission must either emit an explicit trapping block for that exact site without consuming unestablished shape facts, or refuse the target with a precise limitation. It must not infer safety from absent propagation or advisory match coverage. Required originals must determine whether this mechanism is needed before choosing a narrower first slice.

Use a bounded target pass with all cardinalities checked before traversal (F<=256, I<=65536, O<=64, G<=256 and current snapshot/string caps). Precharge every copied getter (current four probes), origin-mask scan, row comparison and counted executable string byte before work. An origin cache may be stack-local and charged as actual sizeof rows, not new persistent metadata. The concrete row/byte allowance and temporary stack extent must be reviewed before source; it is a separate target budget, not an invented addition to old image counters. Source constructor and image retain their current separately bounded phases and source/destination overlap. Free the source plan before simulation/emission. Existing native emitter allocations and shape fixed-point costs remain separately measured, not falsely bounded by the proof budget.

The first exact primitive/string domain must be enumerated from the six actual modules and native byte semantics. Validate counted bytes of executable string operands, not advisory names or unrelated pool suffixes; unsupported executable byte domains refuse explicitly. No generic counted-string parity follows from this union declaration. Unsupported string/array/callable/foreign domains remain explicit target limitations; no new schema or source-spelling filter is introduced. HALT cannot be blanket-refused: retained raw-program.nasm, raw-shadow.nasm and c-shadow.nasm contain failure-arm HALT.

## Canonical identity, payload and lifetime prerequisites

Current AGG_PACK simulation in nvm2c.c boxes variant INT as OPTIONAL/VARIANT_SCALAR; nested record fields carry REC. Current emission calls `nrec_create(count,kind,tag)` for every canonical pack, while nvm2c_record_identity.inc rejects kind!=AGG_RECORD. Merely setting canonical_records would therefore abort on union construction. Emit a union-selected canonical allocator variant with exact permitted kind/count/variant combinations (record count1; declared union payload count1 or empty count0). Existing array/map identity helper text stays unchanged on NULL union routes. Fixed storage/layout can be reused without widening its old allocator contract. Enable all canonical accounting/type dependencies even for unused declarations, including nmap_t and nagg cleanup helpers.

A canonical variant owner retains kind and tag; the containing record field stores the same canonical identity through nrec_snapshot, not a legacy by-value snapshot that loses mutation aliases. Record SET can replace the union edge but cannot mutate the variant's payload or tag. Selected AGG_GET/TAG emission must add exact kind/variant/count/storage guards derived from site facts before payload access; existing generic field-range/kind checks alone are not a nominal proof. None has zero fields and must never read field0. Stored INT remains boxed with exact TAG_INT, and payload GET unboxes after validation.

The root walker in nvm2c_map_roots.inc follows canonical identity and k==REC child pointers without requiring record kind0; `emit_nagg_sweep` in nvm2c.c (~6676) actually frees unrooted canonical owners by identity membership. Both a union reachable only through the containing record and a separately retained old union after record replacement must survive actual forced collection; unreachable owners must become reclaimable. The walker also follows boxed scalar storage and it must be qualified for record→Some/None graphs rather than assumed from map tests. CALL roots locals plus operands before collection and argument consumption; return removes the current root frame without collecting before caller transfer. Tail and helper return paths need actual sole-root tests, including variant returns. Preserve aliases across record field replacement and globals. Forced collection must retain reachable owner identities, and final teardown must free all canonical allocations, including empty variants. Qualify exact OOM abort diagnostics; sanitizer reports are failures, not acceptable aborts.

## Scoped native HALT outcome adapter

Current OP_HALT emission (~6191) calls emit_effect_top into nfx_halt_result, sets nfx_halted and unwinds through L_return. Generated main (~8774) uses residue as an int and skips entry after initializer HALT. Neither behavior is the qualified union policy. Modify neither behavior for old targets.

For the union context only, HALT sets the activation halt marker and goes through existing per-frame L_return cleanup without reading/converting the top operand. CALL observes the marker before consuming a result; TAIL propagates it without fabricating a result. Effect/foreign/callback routes remain excluded. Verify current emit_direct_call's scalar/result-slot publication and post-call marker check cannot dereference an uninitialized record result or collect it as a live guest result on HALT; use a union-only ordering guard where necessary. The existing effect_emit_return suppression while halted is groundwork, not an outcome test.

Propose generated internal interface:

```
typedef enum { NUNION_RETURNED, NUNION_HALTED } nunion_outcome;
static nunion_outcome nunion_invoke(int64_t *returned_value);
```

At invocation start require/establish idle native root/frame state. If an initializer exists, call it once and let its call chain unwind all activation-local frames/root sets. Discard its scalar result. Reset only that completed activation's halt marker and stale halt/top scratch before entry; do not release global owners, reset globals or roll back writes. Entry then executes exactly once. Entry/helper HALT returns NUNION_HALTED without writing returned_value. Normal INT entry return writes it only after actual normal completion and returns NUNION_RETURNED. ASSERT false remains the exact assertion abort; it is not HALTED or a fabricated result. Public native program exit maps HALTED to successful process termination separately from RETURNED's guest INT exit value, so exit0 alone is insufficient evidence: internal generated-harness tests must inspect outcome and an unchanged integer sentinel.

Per-activation cleanup removes nroot frames, dynamic per-function record/local arrays and effect frame bookkeeping. It must not call final nrec/nmap/string release functions after initializer. Global roots remain reachable between initializer and entry and across any explicitly tested repeated internal invocation. Final main teardown releases canonical/global-owned runtime allocations only after the outcome is captured. The retained ordinary native initializer-HALT baseline has stack residue16, not a committed global16: its global remains VOID because entry is skipped. The normal initializer baseline reaches entry and writes global99. A separate future fixture must explicitly STORE_GLOBAL16 before HALT, then establish entry/global99 and preservation of committed initializer owners; I do not claim that ordering from the residue-only baseline. Test root HALT with arbitrary INT/UNION/record residue, helper CALL/TAIL HALT, true ASSERT resume, false ASSERT abort, normal initializer scalar residue, VOID initializer and output sentinel. Compare with the nine ordinary VM baseline cases and retain the existing ordinary-native contrast before implementing the adapter.

Then review and implement independently: target-only module/image validation plus all256 comparisons; union-only canonical identity/shape and outcome adapter; actual six selected translations and O0/O2 ASan/UBSan forced-GC runs; compiler allocation prefixes and separately generated-process OOM prefixes. Public target remains unchanged until later borrowed-state/transport activation. Old map/array output bytes, struct sizes, zero-extra image/constructor metrics and six legacy budgets remain literal. No broader union payload, callable, recursive nominal, or publisher scope is implied.


## Proposed target accounting checkpoint (not implemented)

I propose an independent target allowance of 33,554,432 logical work units and 65,536 bytes of explicitly inventoried temporary storage. These are refusal limits for the new target only, not additional allowances for old constructors or a bound on native C emission. I will measure actual compiled frames before claiming a C-stack bound. No target heap allocation is required. I will not infer fit from the six successful ordinary translations.

The target first spends four units for each of header, execution counts and proof counts, then validates F<=256, I<=65536, O<=64, G<=256 before any indexed traversal. I charge fixed comparisons individually before work. The opcode audit visits all256 values once, charging each visit and comparison. Layout/variant/nominal cardinality is the exact admitted two-layout/two-variant profile, checked before getters. Function arity and instruction ranges are checked before parameter/instruction loops; checked cumulative range must equal I. No malformed count may determine a loop before its cap/range check.

I use one explicit counter with these operations, rather than pretending every row has equal cost:

- Each immutable getter call, including failure, spends four units first. Image wrappers delegate directly to execution/proof getters; no declaration scan is implied by the four-unit interface. Byte-copy getters additionally precharge their exact byte count.
- Each fixed scalar comparison, mask operation and checked arithmetic operation spends one unit before evaluation. Each origin-bit iteration spends one unit plus its actual comparisons; use at most64 checked iterations, not a data-dependent unbounded loop. The origin cache is filled once with O getters, then masks are checked against cached kind/variant/allocation identity without repeated declaration reads.
- Each copied row/byte initialization or copy spends its actual sizeof/count before touching storage. Counted executable literal validation spends length+1 before terminal/NUL scanning; repeated executable uses are charged separately. Read from the immutable image-bound module only after the copied operand index/length correspondence is checked. A string-pool name or unexecuted advisory suffix is not a string-producing instruction.
- A sticky unsupported-domain result does not stop structural/correspondence checking. INVALID, exhausted allowance and allocation failure keep their distinct status. Only complete success publishes the target context. No later emitting path may consult an unvalidated row as an execution capability.

Thus W_target is the measured checked sum `4*N_getters + N_scalar_operations + N_origin_visits + B_copies + B_string_scans`, limited before each operation. Implementation review must enumerate each helper's operations against this schedule; I will not claim the formula covers hidden loops. Target bounds and exact-limit tests use this counter independently of image reservation counters.

The temporary inventory is `64*sizeof(NvmUnionFieldOrigin)` plus one execution instruction/site row, one function row, one header, execution/proof counts, one value-origin row, two layout rows, two variant rows, two field rows, three uint64 origin masks, bounded counter/index scalars and the target context. No I-sized recipe array, F-sized function table or string-length VLA is needed. The context borrows the image and stores only copied exact nominal/layout/variant identities and validated domain choices; it does not cache a caller-controlled trusted flag. Its concrete declaration/sizeof and compiler frame extent are required at the next source checkpoint. Until then65,536 is a proposed ceiling, not a measured extent. Byte staging, if used, must be fixed and included in this inventory.

The module-taking route keeps source constructor phase A, independent source+destination image reconstruction phase B, and image-only target/emission phase C separate. Phase B already accounts for retained source overlap through the image constructor; I do not charge that source twice or refund its reservation. Free the source before C. Target scratch is additive to the live image in C, while emitter buffers/shape allocations remain separately measured and fail atomically. Old image0/0, constructor/proof metrics, public native text and six resource rows must remain exact. No source implementation is authorized by this proposed accounting appendix.
